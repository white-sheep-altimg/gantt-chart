# ガントデータ集計チャート

`data.json` の `data` 配列を読み込み、タスク期間を営業日単位で集計して Chart.js の積み上げ棒グラフとして表示するとともに、DHTMLX Gantt を使ったインタラクティブなガントチャートも併せて表示する HTML アプリケーションです。

![画面例](/images/sample01.png)

## 主な機能

### 集計グラフ（Chart.js）

- 集計単位を「日」「週」「月」から選択
- `start_date` と `end_date` の両日を含めて日数を計算
- 土日を除外
- 日本の固定祝日、ハッピーマンデー、春分の日、秋分の日を除外
- 画面から追加の休日を指定可能
- `process`、`text`、`owner` など、データに存在する任意の項目で積み上げ
- `start_date` と `end_date` 以外の項目名を固定せず動的に候補化
- 値が未定義または空の項目は「未設定」に集約
- データ項目や期間が多い場合はグラフを横スクロールして表示

### ガントチャート（DHTMLX Gantt）

- タスクのグリッド表示（タスク名、部署、開始日、完了日、日数、担当者、進捗、Issue）
- ライブボックスによるタスク編集（タスク名、開始日、完了日、担当者、Issue）
- タスクのドラッグによる期間変更・移動
- 進捗の「済/未/パーセント」表示
- 選択行のハイライト
- 週末の背景色強調
- 今日（当日）の位置に赤いラインを表示
- Issue 番号（`#` 付き）をダブルクリックで新規タブで開く
- ガントチャートでのタスク更新時に集計グラフを自動反映
- 「保存」ボタンでタスクデータを JSON としてダウンロード
- 「更新」ボタンでファイルパスを指定してデータリロード
- リンク（依存関係）の色分け（finish-to-start / start-to-start / finish-to-finish）

## 起動方法

`data.json` はブラウザの `fetch` で読み込むため、HTML ファイルを直接ダブルクリックするのではなく、HTTP サーバー経由で開きます。

```bash
cd /Users/hsato/Projects/gantt-chart
python3 -m http.server 8000
```

ブラウザで次の URL を開きます。

```text
http://localhost:8000/index.html
```

Chart.js は次の CDN から読み込みます。CDN へ接続できない環境では、Chart.js をローカル配置し、`index.html` の読み込み先を変更してください。

```text
https://cdn.jsdelivr.net/npm/chart.js@4.4.4/dist/chart.umd.min.js
```

## 使い方

### 集計グラフ

1. `index.html` を HTTP サーバー経由で開きます。
2. 「集計単位」で「日」「週」「月」のいずれかを選択します。
3. 「積み上げ項目」で、例えば `process`、`text`、`owner` などを選択します。
4. 必要に応じて、追加する休日を `YYYY-MM-DD` 形式で入力します。
5. 複数指定する場合はカンマで区切ります。
6. 「再集計」を押すとグラフが更新されます。

入力例：

```text
2026-07-20,2026-08-11
```

項目数が多い場合は、グラフ表示領域を左右にスクロールしてください。

### ガントチャート

- グリッドのセルを直接編集してタスク情報を変更できます。
- ガントチャート上のバーをドラッグして期間を変更・移動できます。
- タスクをダブルクリックすると、Issue 番号がある場合にその Issue ページを新規タブで開きます。
- 「保存」ボタンで現在のタスクデータを JSON としてダウンロードできます。
- 「更新」ボタンでデータファイルのパスを入力し、リロードできます。

## `data.json` の形式

最低限、各要素に `start_date` と `end_date` が必要です。その他の項目名は固定されていません。

```json
{
  "data": [
    {
      "text": "タスクA",
      "process": "設計",
      "start_date": "2026-07-06",
      "end_date": "2026-07-12",
      "duration": 6,
      "progress": 0.6,
      "owner": "山田 花子",
      "issue": "#1020",
      "parent": 0
    }
  ],
  "links": [
    {
      "id": 1,
      "source": 1,
      "target": 2,
      "type": "0"
    }
  ],
  "baselines": []
}
```

**タスクフィールド:**

| フィールド | 説明 |
| --- | --- |
| `id` | タスクの一意な ID |
| `text` | タスク名 |
| `process` | 部署・工程区分 |
| `start_date` | 開始日（`YYYY-MM-DD`） |
| `end_date` | 完了日（`YYYY-MM-DD`） |
| `duration` | 日数 |
| `progress` | 進捗率（0〜1） |
| `owner` | 担当者 |
| `issue` | Issue 番号（`#` 付き） |
| `parent` | 親タスクの ID（0 または省略で独立） |

**リンク（依存関係）タイプ:**

| type | 内容 |
| --- | --- |
| `"0"` | finish-to-start（完了→開始） |
| `"1"` | start-to-start（開始→開始） |
| `"2"` | finish-to-finish（完了→完了） |

`start_date`、`end_date` 以外のキーは、データ全体から自動的に抽出されて積み上げ項目の候補になります。ある要素に選択項目の値がない場合は「未設定」として集計されます。

## 集計ルール

### 日数

`start_date` と `end_date` の間を1日ずつ走査し、次の条件を満たす日だけを1日として加算します。

- 土曜日・日曜日ではない
- 祝日として登録されていない

したがって、例えば月曜日から日曜日までの期間は、祝日がなければ通常5日として集計されます。

### 週

月曜日始まりの週として集計します。表示は `YYYY年 第NN週` 形式です。

### 月

暦月単位で集計します。表示は `YYYY年MM月` 形式です。

### 積み上げ

選択した項目の値ごとにデータセットを作成します。例えば `process` を選択すると、「設計」「開発」「未設定」などが積み上がります。

## サンプルデータでの確認例

現在の `data.json` で `process`、集計単位「月」を選択した場合、2026年7月は次のように集計されます。

| 項目 | 日数 |
| --- | ---: |
| 業務・要件 | 5 |
| 設計 | 13 |
| 開発 | 13 |
| 未設定 | 3 |

## 休日に関する注意

土日は常に除外します。祝日はコード内で日本の一般的な祝日を計算していますが、振替休日、国民の休日、臨時休日、将来の制度変更までは完全には網羅していません。

正確な休日を反映する必要がある場合は、画面の「追加する休日」欄で指定してください。例えば振替休日を追加する場合は、次のように入力します。

```text
2026-05-06
```

## 実装上の注意

- ブラウザで動作する vanilla JavaScript で実装しています。
- グラフ描画には Chart.js 4.4.4 を使用しています。
- ガントチャートには DHTMLX Gantt を使用しています。
- `data.json` の読み込みに失敗した場合は、画面上にエラーを表示します。
- 日付が不正、または `start_date` が `end_date` より後の要素は集計対象外になります。
- `duration` や `progress` は集計には参照せず、必ず `start_date` と `end_date` から日数を計算します。
- ガントチャートでのタスク更新（ドラッグによる期間変更含む）は `onAfterTaskUpdate` / `onAfterTaskDrag` で検知し、集計グラフを自動更新します。
- 「更新」ボタンで指定したファイルパスは localStorage の `gantt_source_json` に保存され、次回以降自動的に復元されます。
- Issue 番号をダブルクリックすると、`GIT_REMOTE_URI` + `PROJECT_NAME` + `/issues/` + Issue番号 の URL を新規タブで開きます（デフォルト: `http://localhost:3000/foo/issues/...`）。
